# Security policy

## Reporting a vulnerability

Please **do not** open a public issue for a security vulnerability.

Instead, use GitHub's private vulnerability reporting: go to the **Security** tab of this repository, then **Report a vulnerability**. This opens a private conversation with the maintainer, without exposing the issue publicly before a fix is available.

Include, if possible:
- A description of the vulnerability and its potential impact.
- Steps to reproduce it.
- The affected file(s) or commit.

## Scope

This is a personal, non-commercial project. There is no bug bounty. Reports about the `main` branch are in scope; forks and unrelated third-party services are not.

## Response

This project is maintained by one person outside working hours on other commitments. There is no guaranteed response time, but security reports are prioritized over regular feature work.
